# SAPPHIRE Sales Analytics Project

## Project Overview
This project analyzes SAPPHIRE's historical sales and order data to identify revenue trends, product performance, category-level insights, city-wise order patterns, and discount-related sales behavior.

## Objectives
- Analyze year-over-year revenue trends.
- Identify top-performing products and categories.
- Explore seasonal sales patterns.
- Analyze city-wise orders and product demand.
- Examine relationships between price, discounts, units sold, and revenue.
- Identify unusual monthly and SKU-level performance.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Visualizations
The project includes 16 visualizations covering revenue trends, category analysis, top SKUs, city-wise orders, price bands, performance classification, and anomaly detection.

## Methodology
Data aggregation, exploratory data analysis (EDA), correlation analysis, quantile-based segmentation, and interquartile range (IQR) outlier detection.

## Key Learning Outcomes
- Data cleaning and aggregation
- Business-oriented data analysis
- Statistical interpretation
- Data visualization
- Communicating insights through Python

## Project Files
- `SAPPHIRE_Sales_Analytics.ipynb` — notebook containing analysis and visualizations.
- `Images.zip` —  contains visualizations.
- `Sapphire.zip` — contains dataset from kaggle.

## Notes
The 2026 data covers January through September, so comparisons with complete calendar years should be interpreted carefully.

This project is intended for educational and portfolio purposes.
